# Legacy: the 2025 draft tools

The scripts, notebook and dashboard used for the 2025 draft, kept for reference only. They are replaced by the
`fantasy_draft` package and `run_dashboard.py` in the project root.

They are not maintained and will not run as they are: they read a CSV from a path that no longer exists and
rely on a 450 MB pre-computed team file. They are excluded from the project's lint settings.
